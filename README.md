# vpn-speedtest

Живой спидтест для Clash: **https://ros-ua.github.io/vpn-speedtest/**

Открой страницу, нажми «Старт» и переключай ноды/протоколы в Clash —
страница сама замечает смену IP, отмечает это на графике и собирает
таблицу-рейтинг «какая нода сколько выдала». Тест идёт непрерывно,
пока не нажмёшь «Стоп» — перезапускать страницу не нужно.

## Как пользоваться

1. «Старт» — пошёл непрерывный замер (64 потока по 6 доменам-источникам).
2. Переключил ноду в Clash → IP сменился → страница сама начнёт новый
   замер (старые соединения перезапустит, чтобы мерить честно новую ноду).
3. Сменил протокол на том же сервере (IP не меняется) — жми «⚑ Новый замер».
4. Таблица справа: текущий замер сверху, остальные отсортированы по скорости.

## Советы

- В Clash Verge включи **Auto Close Connections** — тогда при переключении
  старые соединения не висят на прежней ноде.
- Первые ~5 секунд каждого замера (разгон) в среднюю не идут.
- «⚡ Бёрст» — +64 потока на 8 секунд, кратковременный максимум нагрузки.

## Устройство

- Один файл `index.html`, без сборки. Chart.js лежит рядом (`chart.umd.js`),
  внешних зависимостей при загрузке нет.
- Источники трафика: `speed.cloudflare.com` + 4 зеркала jsDelivr + unpkg —
  6 разных доменов = до 6 параллельных TCP-соединений (HTTP/2 склеивает
  все запросы к одному домену в одно соединение, поэтому доменов несколько).
- IP определяется через ipwho.is / ipapi.co / ipinfo.io (опрос раз в 3 сек).
